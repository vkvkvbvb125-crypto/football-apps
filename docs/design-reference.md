# 킥데이(KickDay) 디자인 레퍼런스

클로드 디자인(claude.ai/design)에 새 화면을 프롬프트로 만들 때, 아래 내용을 프롬프트에 붙여넣으면 실제 앱과 비슷한 톤으로 결과물이 나옵니다. 이 문서는 실제 코드(`src/`)에서 쓰이는 값을 그대로 뽑은 것입니다.

## 색상

| 역할 | 값 |
|---|---|

| 카드/패널 배경 | `#141A17` (기본 카드), `#1B231F` (보조/하이라이트) |

| 강조(그린) | `#4ADE80` (버튼/링크/활성 상태 메인), `#35F58A` (하단 네비 활성), `#50D978` (타이머 CTA/진행 링) |
| 텍스트 - 기본 | `#FFFFFF`, `#E7ECE9` |
| 텍스트 - 보조 | `#8A9490`, `#87918F` |
| 텍스트 - 플레이스홀더 | `#5A625E` |
| 에러/위험 | `#F87171` |

| 오버레이 | 모달 배경 `rgba(0,0,0,0.6)`, 그림자 `rgba(0,0,0,0.4)` |

## 타이포그래피

| 용도 | 크기 | 굵기 |

## 여백 / 모서리

- **borderRadius**: 알약형 버튼 `999`, 카드/패널 `14`(기본값), 인풋/버튼 `10`, 큰 장식 도형 `20~60`
- **간격 스케일**: 4 / 6 / 8 / 10 / 12 / 14 / 16 / 20 / 24 (2·4 배수)
- 카드 내부 padding: `16` 또는 `20`
- 화면 좌우 padding: `20` (일부 압축 화면은 `11~12`)
- 버튼 세로 padding: `12~14`

## 컴포넌트 패턴

- **카드**: 배경 `#141A17`, `borderWidth:1`, 테두리 `#22302A`, `borderRadius:14`, `padding:16`, 내부 요소 간격 `8~10`
- **주요 버튼**: 완전한 알약이 아닌 둥근 사각형(`borderRadius:16`), 초록 배경 + 어두운 텍스트(`#0F1512`)
- **탭/필터 토글**: 알약형(`borderRadius:999`) 버튼, 활성 시 초록 배경/테두리
- **하단 네비게이션**: 화면 하단에 8px 여백을 두고 떠 있는 둥근 바(`borderRadius:9`), 반투명 배경 `rgba(6,14,14,0.96)`, 얇은 테두리 `rgba(85,110,108,0.35)`, 은은한 그림자. 중앙 탭만 이중 링 원형 버튼으로 돌출.
- **원형 진행 링(타이머 등)**: SVG 링, 트랙 `#173A28` + 진행 `#50D978`, `strokeWidth:5`, 끝을 둥글게(`strokeLinecap:round`), 12시 방향에서 시작.

## 아이콘

`Ionicons`(@expo/vector-icons) 사용. 크기는 대부분 `12~20px`(강조 아이콘 최대 28px). 비활성 상태는 outline(`*-outline`), 활성 상태는 채워진(`filled`) 버전으로 전환.

### 프롬프트에 붙여넣을 한 줄 요약 (짧은 버전)

> 다크 테마(#0F1512 배경, #141A17 카드, #22302A 테두리), 라임 그린(#4ADE80) 강조색, 시스템 기본 폰트, 카드 radius 14 / 버튼 radius 10~16, 알약형 토글, Ionicons 아이콘(outline↔filled 전환) 스타일로 디자인해줘.
