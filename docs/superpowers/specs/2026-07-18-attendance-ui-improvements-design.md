# 일정(참석투표) 화면 UI 개선 설계

## 배경

케밥메뉴(수정/삭제)를 방금 전체화면 바텀시트로 구현했는데, 옵션이 두 개뿐인데도 화면 하단을 크게 가려서 과함. 경기 시간 입력도 30분 단위 프리셋 칩 가로스크롤 방식인데, 더 명확하게 시간을 직접 고르는 방식을 원함.

## 1. 케밥메뉴: 앵커 팝오버로 교체

- 대상 파일: `src/features/attendance/screens/AttendanceScreen.tsx`
- 기존 `actionMatch` 기반 전체화면 Modal(바텀시트)을 제거
- 케밥(⋮) 아이콘의 `onPress` 이벤트에서 `nativeEvent.pageY`(및 필요시 `pageX`)를 읽어, 그 좌표 근처에 작은 팝오버 카드를 띄움
- 팝오버는 `TabHeader`의 알림 패널과 동일한 시각 패턴(다크 카드, 테두리, 그림자) 재사용: "수정" / "삭제" 두 줄, 바깥 영역 탭하면 닫힘
- 위치 계산: `top: pageY + 8`, `right: 16` 고정(카드가 항상 화면 오른쪽에 오도록) — 스크롤 리스트 안에서도 press 시점의 절대 좌표를 쓰므로 별도 measure 불필요

## 2. 경기 시간 입력: 시/분 휠 피커로 교체

- 새 컴포넌트: `src/features/attendance/components/TimeWheelPicker.tsx` (기존 `TimeSlotPicker.tsx` 대체, 사용처 전부 교체 후 기존 파일 삭제)
- 평소엔 현재 선택된 시간(`19:00` 등)을 보여주는 버튼 하나만 표시. 탭하면 모달 오픈
- 모달 구성: 시(06~23, 18개) / 분(00,10,20,30,40,50, 6개) 두 개의 세로 스크롤 휠을 나란히 배치, 스크롤 스냅으로 가운데 항목이 선택값. 하단 "취소"/"확인" 버튼(기존 모달 버튼 스타일 재사용: `modalCancelButton`/`modalCreateButton`)
- 확인 시 `"HH:MM"` 문자열을 `onChange`로 전달 — `AttendanceScreen`의 `timeText` state와 인터페이스 동일하게 유지해서 호출부 변경 최소화

## 범위 밖

- 두 항목 모두 프론트엔드 컴포넌트 변경만 포함, DB 스키마/백엔드 변경 없음
- 새 기능(공지사항+알림, 팀채팅, 날씨연동, 구장예약)과 수익화 논의는 별도 세션에서 다룸
