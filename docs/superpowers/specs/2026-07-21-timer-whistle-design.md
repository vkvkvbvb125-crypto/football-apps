# 타이머 휘슬음 추가 + 교체대기열/쿼터 개념 제거 설계

## 배경

경기운영 탭의 타이머(`TimerPanel.tsx`)는 쿼터 카운트다운, 시작/일시정지/다음쿼터, 종료 시 진동까지 이미 동작한다. 이번 작업으로 세 가지를 처리한다:

1. 타이머 종료 시 진동뿐 아니라 휘슬 소리도 나도록 추가하고, 시작/재개 시에도 짧게 한 번 울리도록 한다.
2. "교체 대기 순서" 섹션을 제거한다 — 이 팀은 팀 대 팀으로 경기를 진행하기 때문에(이미 구현된 팀분배 기능으로 고정 배정), 개인별 교체 순환이라는 개념 자체가 실제 사용 방식과 맞지 않는다.
3. "쿼터" 개념을 제거하고 단순 카운트다운 타이머로 바꾼다 — "1쿼터/2쿼터..." 라벨과 "다음 쿼터" 버튼을 없애고, 설정한 시간을 세다가 0이 되면 휘슬이 울리는 단순한 반복 카운트다운만 남긴다.

## 목표

- 시작/재개 시 휘슬 소리 1회 재생
- 카운트다운 종료 시 진동(기존 유지) + 휘슬 소리를 짧은 간격으로 3회 연속 재생 (시작음과 소리 파일은 동일, 재생 횟수로 시작/종료를 구분)
- "교체 대기 순서" UI 및 관련 상태/로직 전체 제거
- "쿼터" 라벨/번호/"다음 쿼터" 버튼 제거, 시간 설정 + 카운트다운 + 시작/일시정지 + 초기화만 남김

## 오디오 재생 방식

Expo SDK 57 기준 `expo-av`의 Audio 모듈은 deprecated되어 v57 버전 문서에서 빠졌고, 현재 권장 패키지는 `expo-audio`다. `useAudioPlayer(source)` 훅으로 플레이어를 만들고 `.play()`로 재생한다. 재생마다 처음으로 되감아야 하므로 매번 `.seekTo(0)` 후 `.play()`를 호출한다. iOS 무음 모드에서도 들리도록 컴포넌트 마운트 시 `setAudioModeAsync({ playsInSilentMode: true })`를 한 번 호출한다.

휘슬 파일은 하나만 쓴다 (`app/assets/sounds/whistle.mp3`, 사용자가 직접 준비해서 넣음):
- 시작/재개: 1회 재생
- 카운트다운 종료: 약 450ms 간격으로 3회 연속 재생 (`setTimeout`으로 재생 시점을 스태거링 — 정밀한 오디오 스케줄링은 필요 없는 캐주얼 기능이라 이 정도로 충분)

시작 신호는 "시작" 버튼을 누르는 시점에 `isRunning`이 `false`인 경우에만 재생한다 (일시정지로 전환할 때는 울리지 않음). 이렇게 하면 최초 시작과 일시정지 후 재개 모두 자연스럽게 커버된다.

## 교체 대기 순서 제거

`TimerPanel.tsx`에서 다음을 전부 제거한다:
- `useTeamStore`에서 가져오던 `members` (다른 용도로 쓰이지 않으므로 import 자체도 제거)
- `queue` state와 이를 초기화하는 `useEffect`
- `rotateQueue`, `nameFor` 함수
- "교체 대기 순서" 섹션 JSX(제목/안내문구/리스트)
- 관련 스타일(`sectionTitle`, `sectionHint`, `queueList`, `queueRow`, `queueOrder`, `queueName`)

## 쿼터 개념 제거

`TimerPanel.tsx`에서 다음을 제거/변경한다:
- `quarterNumber` state 및 이를 보여주는 `<Text style={styles.quarterLabel}>{quarterNumber}쿼터</Text>` 삭제
- `handleNextQuarter` 함수와 "다음 쿼터" 버튼 삭제 (쿼터 번호가 없으니 "초기화" 버튼과 기능이 중복됨)
- "쿼터 시간(분)" 라벨 텍스트를 "타이머 시간(분)"으로 변경 (내부 변수명 `quarterMinutes`는 그대로 두되, 사용자에게 보이는 문구만 "쿼터"라는 단어를 뺌)
- 남는 컨트롤: 초기화, 시작/일시정지 두 개만

## 검증 방법

테스트 프레임워크가 없으므로 `npx tsc --noEmit` + 수동 확인으로 검증한다. 수동 확인 시나리오:
1. "시작"을 누르면 휘슬이 1번 울리는지
2. "일시정지"를 누를 땐 안 울리는지
3. 다시 "시작"(재개)을 누르면 또 1번 울리는지
4. 타이머 시간을 짧게 설정해 카운트다운이 0이 될 때까지 기다려 진동+휘슬 3연타가 함께 나는지
5. "교체 대기 순서" 섹션이 화면에서 완전히 사라졌는지
6. "N쿼터" 라벨과 "다음 쿼터" 버튼이 화면에서 사라지고, "초기화"/"시작" 두 버튼만 남았는지

## 사용자 액션

`app/assets/sounds/whistle.mp3` 파일을 사용자가 직접 준비해서 해당 경로에 추가해야 코드가 정상적으로 번들링된다. 파일이 없으면 `require()` 시점에 Metro 번들러가 에러를 낸다.
